# DOM Practice Project

## Short Description

A simple interactive web application demonstrating DOM manipulation techniques with a modern UI.

## Features Implemented

- **Dark Mode**: Toggle between light and dark themes with icon changes
- **Cards**: Interactive activity cards with add functionality
- **Search**: Real-time search functionality for the dynamic list
- **Dynamic List**: Add and remove items from a list with search filtering
- **Text Manipulation**: Change text content dynamically
- **Input Display**: Enter and display user input
- **Responsive Navigation**: Mobile-friendly hamburger menu
- **Dropdown Menu**: Services submenu

## What the Project Demonstrates

This project demonstrates fundamental DOM manipulation techniques including:

- Event handling (click, input, mouseover)
- Dynamic element creation and removal
- CSS class toggling for theme switching
- Form input handling
- Responsive design principles
- JavaScript array manipulation for list management
